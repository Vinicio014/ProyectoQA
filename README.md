# Aplicacion Web - Uniformes Deportivos
Esta aplicacion web consiste en gestionar el inventarios de una empresa dedicada al desarrollo de uniformes deportivos.

El objetivo de esta aplicacion web, es automatizar la gestion, compra y venta de uniformes deportivos que dia a dia reliza la empresa.

--------
### Teconologias usadas
#### - Backend:
- Php
    
#### - Frontend
- HTML
- CSS
- JavaScript

#### - Base de datos:
- MySQL

#### - Editor de Texto:
- Vs code

-----

-----------------

## Instalacion
#### - clonar el repositorio
    - git clone "agregar el enlace del repositorio"
    - Abir carpeta creada en vs code
    
    - la base de datos se encuetra en la carpeta backend llamada: Uniformes_Depostivos.sql
